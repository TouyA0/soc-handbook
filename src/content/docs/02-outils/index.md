Une cheat sheet par outil, pour retrouver en quelques secondes le filtre ou la commande dont on a besoin en pleine investigation. Pas de cours : chaque ligne est un filtre, une commande ou une action, avec ce qu'elle fait.

Sur le réseau, les deux outils se complètent : **Wireshark** pour ouvrir une capture et l'analyser paquet par paquet, **Snort** pour lui appliquer des règles et faire ressortir d'un coup les motifs déjà connus.

Pour s'en servir vite :

- le champ **Filtrer cette page** en haut de chaque cheat sheet ne garde que les lignes qui contiennent les mots tapés ;
- le bouton **Copier** d'une ligne copie le filtre ou la commande ;
- depuis n'importe quelle page, **Ctrl K** puis le préfixe `f:` cherche un filtre dans toute la base, cheat sheets et fiches techniques comprises.

Les fiches techniques de [Menaces & détection](../03-menaces-detection/index.md) reprennent ces outils sur un cas précis : quel filtre, sur quelle trace, pour quelle attaque.
